Which subshell fills next? The diagonal rule

Write the subshells as a staircase (shell n has n subshells), draw diagonal arrows from top-right to bottom-left, and read the arrows in order. The number in each corner is the filling order.

  1. Write the staircase. 1s · 2s 2p · 3s 3p 3d · 4s 4p 4d 4f · 5s 5p 5d 5f · 6s 6p 6d · 7s 7p.
  2. Draw the diagonal arrows from the top-right of each row down to the bottom-left.
  3. Read the arrows top to bottom; inside each arrow go from its upper-right end to its lower-left end.
  4. Fill each subshell to capacity before moving on: s holds 2, p 6, d 10, f 14.
Why 4s before 3d? Energy decides, not shell number — 4s sits a little lower than 3d, so potassium's 19th electron goes into 4s. Memory hook: the periodic table read left to right, row by row, is this order: s on the left, d in the middle (one shell behind), f below (two behind), p on the right.

The four blocks of the periodic table

Each block is the kind of orbital the element's last electron goes into, and the block's width equals how many electrons that orbital type holds: s = 2, p = 6, d = 10, f = 14. That's the reason for the table's staircase shape.

s-block — groups 1–2 (+ helium). Alkali & alkaline earth metals. Na = [Ne] 3s¹
p-block — groups 13–18. Most nonmetals, metalloids, halogens, noble gases. Cl = [Ne] 3s² 3p⁵
d-block — groups 3–12. The transition metals. Fe = [Ar] 3d⁶ 4s²
f-block — the two rows below. Lanthanides & actinides. U = [Rn] 5f³ 6d¹ 7s²
Helium sits with the noble gases because it behaves like one, but its configuration is 1s² — so it's really an s-block element (dashed outline). Rule of thumb: the letter of the last term in a configuration tells you the block.
